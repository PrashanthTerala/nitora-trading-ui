# Lesson videos

Narrated lesson videos, rendered with [Remotion](https://www.remotion.dev) from the site's own
components: the same `CandleSvg`, indicator engine, synthetic data, design tokens and fonts as
the lessons. This folder is not part of the site build and has its own `package.json`. Nothing
here is published; a video reaches the site only after review and a separate decision.

| Video | Lesson | Languages | Status |
|---|---|---|---|
| `ma-crossovers` | m05-indicators/03-ma-crossovers | en, te, es | pilot: en approved; te, es awaiting review |
| `engulfing` | m02-candlestick-patterns/06-engulfing | en, te | prototype |

Planning documents: `../docs/video-production/` (the Phase 0 report and the curriculum
inventory, generated by `scripts/inventory.mjs` into it and into `manifests/curriculum.json`).

## Setup, once

```bash
npm install
python -m venv .piper
.piper/Scripts/python -m pip install piper-tts==1.8.0
.piper/Scripts/python -m piper.download_voices --download-dir .piper/voices en_US-ljspeech-high te_IN-venkatesh-medium es_MX-ald-medium
```

Narration uses [Piper](https://github.com/OHF-Voice/piper1-gpl), a text-to-speech engine that
runs entirely on this machine. Nothing is sent online. `.piper/` is not committed.

Use only voices whose training data allows public use; each voice's `MODEL_CARD` on
huggingface.co/rhasspy/piper-voices names its dataset and licence. `en_US-ljspeech-high` is
public domain; `te_IN-venkatesh-medium` and `te_IN-padmavathi-medium` are CC BY 4.0 (credit
the IndicVoices-R dataset). `es_MX-ald-medium` is trained on an Unlicense dataset, fine-tuned from
the CC0 `es_ES-davefx` voice. **Do not use `en_US-lessac-*`**: its dataset is licensed for research
only. `es_MX-claude-high` names no dataset, only a demo page, so its provenance is unknown.

## Make a video

```bash
node scripts/check.mjs ma-crossovers                         # script still matches the lesson and the engine
.piper/Scripts/python scripts/narrate.py ma-crossovers       # speak every language (or: ... ma-crossovers te)
npm run render -- ma-crossovers-en out/ma-crossovers-en.mp4 --browser-executable="C:\Program Files\Google\Chrome\Application\chrome.exe"
```

There is one composition per video and language (`ma-crossovers-en`, `engulfing-te`, ...), each
timed to its own narration. `npm run studio` opens a live preview. Without
`--browser-executable` Remotion downloads its own headless Chrome on first render.

## Blender shots and QA

```bash
npm run scene-data                                           # build/brand.json + build/<video>.json from the engine
.blender/blender-5.2.2-windows-x64/blender.exe -b --factory-startup -P blender/render.py -- --scene data_landscape --out public/blender/data-landscape/preview --res 960x540 --samples 8
python scripts/qa.py --sheet out/v2/poc-hybrid-intro.mp4     # probe, loudness, clipping, silence, black frames, subtitles
```

Blender 5.2.2 LTS (portable, in `.blender/`, not committed) renders script-built scenes to PNG
sequences in `public/blender/`. Remotion plays them frame-for-frame with `BlenderSequence`
(`src/HybridIntro.tsx`). Eevee, not Cycles, on this hardware: see
`../docs/video-production/HYBRID_VIDEO_ARCHITECTURE.md`. `public/` is the videos' public folder,
filled by `scripts/sync-public.mjs` from the site's `public/` plus generated media.

## How it fits together

- `narration/<video>.json` is the script. It records the lesson file and its sha256, the lesson
  lines each scene draws on, and, per language, a voice, a speed and one passage per scene.
  Keep it to what the lesson says. `scripts/check.mjs` fails when the lesson has changed since,
  when a cited line does not exist, when a language is missing a scene, or when a number the
  narration takes from the chart (`computed`) differs from what the engine calculates.
- `scripts/narrate.py` turns the script into one WAV per scene and language, plus a generated
  `narration/<video>/index.ts` with each recording's length (both regenerated, not committed).
- `src/kit.tsx` holds what every video shares: per-language timing (a scene lasts as long as
  its narration in that language plus a short pause, and its animations stretch with it), the
  scene frame, and the house style.
- `src/MaCrossovers.tsx` and `src/Engulfing.tsx` are the videos. `src/ma-crossovers/data.ts`
  computes every chart value with the site's indicator engine on synthetic series.
- `remotion.config.ts` points `@/` at the site's `src/`, uses the site's `public/` for fonts
  and art, and hands `src/styles/tokens.css` to `src/theme.tsx`, which resolves the dark theme
  with the site's own token parser.

All figures use the synthetic market, so the videos carry no licensed market data.
